## How to act on this

Drift is a symptom, not a verdict. First check whether the data is wrong (a broken feed or a renamed code): fix it, do not retrain. If the data is right, check real performance on the late labels (step 14). Only if performance dropped, retrain, and let the new model enter as a challenger through the gate and promotion rule.
